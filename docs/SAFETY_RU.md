# Безопасная работа с исходниками

- Не запускай fastboot flash или dd для артефактов этой заготовки.
- Huawei ABL может отклонять fastboot boot даже при unlocked.
- Храни резервные копии boot, dtbo, ramdisk и их хэши отдельно от публичного репозитория.
- Не публикуй личные дампы abl/xbl/boot, серийные номера и MAC-адреса.
- GitHub Actions собирает только отдельную диагностическую EFI-программу, НЕ полноценную прошивку.
