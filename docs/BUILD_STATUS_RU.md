# Статус DBY-W09 EDK2

Подтверждено пользователем: **Huawei MatePad 11 DBY-W09**, плата DBY, платформа kona, Qualcomm qcom, Linux 4.19.81+.

Прошивка сообщает `devmodel=DBY-W09S`, но это не корректировка заявленной модели.

- Active DTBO index = 3; name DBY_W09_VD.
- Stock XBL OEM FV 0x9FC00000 + 0x300000.
- Project Aloha upstream SM8250 default 0x9FC41000 + 0x2BF000.
- Память, ACPI, DTB, DXE и аппаратная инициализация не проверены.
- GitHub Actions собирает исключительно пробное AArch64 EFI-приложение.
- Полный `KonaPkg` **скомпилирован** в CI для цели `huawei-dby-w09`, но с заимствованными компонентами от `qcom-mtp8250`; это **не подтверждает аппаратную совместимость с DBY-W09**. См. `FULL_KONA_CI_RU.md`.
- UEFI Shell и Windows ARM64 НЕ запущены.
- Любой сгенерированный из этих исходников образ нельзя считать безопасным для прошивки.

## DBY-W09 VD hardware-audit: новый этап

Полный KonaPkg пересобран в CI после исключения донорского MTP8250 DSDT и Android DTB. Добавлены отдельные исходники VD rootparam и диагностическая DSDT, CI скомпилировал `.dtbo` / `.aml`, проверил 38 зарезервированных диапазонов памяти и изготовил `SM8250_EFI.fd` (2 879 488 байт). [Успешная сборка](https://github.com/danilafilippkin092-debug/upgraded-memory/actions/runs/43282797748). Это не функциональная прошивка: донорские DXE/общие ACPI остаются, отсутствуют настоящие аппаратные протоколы и тестирование запуска.

В локальном OEM XBL-архиве обнаружено 89 AARCH64 EFI-модулей; инструменты для их безопасной *инвентаризации* добавлены, сами бинарники в репозиторий не выкладываются.
